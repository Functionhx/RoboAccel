# Goal 4 · §4–§7 最小实验设计

对应 goal4.md 的第 4、5、7 节，以及用户列表中的第 4、5 项：
**设计**冻结 base 的残差 QAT，和 FP32 教师对照。

本文是设计文档，不是结果文档。每个实验都写明：
架构、初始化、参数量、界限、**可证伪的预测**、以及**判定它失败的条件**。

---

## 0. 一个先决条件 —— 由 Goal 5 的机制发现强加

**任何在自适应 KL 控制器下运行的 W8A8 实验，都不构成对本节假设的检验。**

Goal 5 测得：W8A8 下一次 `1e-5`（算法自己的学习率下限）的权重扰动
产生策略 KL `6.73e-02`，是控制器阈值 `0.01` 的 6.7 倍；
在 2563× 的步长跨度上，KL 只涨 68×（指数 0.54，而浮点是 2.00）。
后果是学习率被钉在下限 **2000/2000 次迭代**。

> **如果残差分支在同一个控制器下训练，它会撞上同一堵墙，
> 而实验将无法区分"残差方案无效"和"优化器根本没动"。**

因此**所有**下列实验都必须带：

```
--schedule fixed --learning-rate 2.563e-4
```

并附优化器读回断言（`train_policy.py` 已实现）。
`2.563e-4` 是 FP32 对照 2000 步学习率的**中位数**，不是随手取的值。

**这条是本设计文档最重要的一句话。** 它是 Goal 5 反馈给 Goal 4 的结果：
在机制被测量出来之前，这两个实验都会被设计错。

## 1. 实验 E-R · 冻结 base + 有界残差

### 架构

```
u(x) = u_anchor(x) + alpha * tanh(r_phi(x))
```

| 项 | 取值 | 理由 |
|---|---|---|
| `anchor` | **W8A8 PTQ 策略**（由 `SOLID_FP32_V2` 直接 PTQ 得到） | goal4.md §4 首选。它已经在 W8A8 数值域内，且**保留了可测量的转向能力**（`turn_left` 0.758 / `turn_right` 0.523），残差只需补回 PTQ 丢掉的部分 |
| `anchor` 参数 | **全部冻结**，`requires_grad=False` | 破坏参考策略在构造上不可能发生——这正是当前 QAT 的失败方式（arm A 七段全 0.000） |
| `r_phi` | `Linear(28→32) → ELU → Linear(32→6)` | 复用 actor 的输入（CONCAT 之后的 28 维），**不引入新的算子** |
| 初始化 | 末层权重与 bias **全零** | `t=0` 时 `u = u_anchor` **逐位相等**，不是近似相等 |
| `alpha` | `0.1`（动作单位） | 上界。动作幅度实测 ±20，0.1 允许 0.5% 的修正 |
| 可训练参数 | 28×32 + 32 + 32×6 + 6 = **1,126** | 对比全策略 QAT 的 38,825，**自由度低 34×** |
| 冻结参数 | 38,825 | |

### 硬件映射 —— 不需要新原语

末层是 `W_b a + c_b + W_r b + c_r`，可按 D7 已验证的方式降为一次 GEMM：

```
[W_b | W_r] [a ; b] + (c_b + c_r)      CONCAT → fused GEMM
```

`fuse_residual_actor.py` 已在真实权重上验证，最大差 **4.8e-07**。

**但 `tanh` 不在 SFU ROM 里**（ROM 只有 ELU）。两个选择：

1. **`alpha * tanh` 只用于训练，导出前检查实际修正幅度**。
   若 `|r_phi(x)|` 在标定集上从未接近 `alpha`，`tanh` 就是恒等映射，
   可以安全去掉后再融合。**必须测量后再决定，不能假设。**
2. 若确实饱和，则用 `clamp` 代替 `tanh`——PL 的 `OP_AFFINE`
   加饱和逻辑可以表达，但**这需要 exporter 支持，当前不生成该描述符**。

方案 1 优先。若必须走方案 2，按 goal4.md §6 的要求，
**先报告这个取舍，再动 RTL**。

> ⚠ 还有一条硬约束：`fixed_ref.check_residual_concat` 要求
> `frac(anchor 输入) == frac(residual 输入)`，因为 **PL 的 CONCAT 不能重量化**。
> 两条分支必须共用同一个激活网格。

### 预测（先写下，才可能被证伪）

* **支持假设**：`turn_left` / `turn_right` 的 `success` 从 PTQ 的 0.758 / 0.523
  上升，且**浮点执行（arm A）不再全零**——即参考策略被保住了。
* **证伪**：转向不升，或 arm A 仍然全零。
  后者尤其关键：anchor 冻结时 arm A 全零在构造上**不应该发生**，
  若发生则说明是残差分支本身学会了依赖量化器，
  假设 H0（"只学修正"）随之失效。

### 判定它无效的条件

1. 转向 `success` 相对 PTQ 提升 < 0.05（三个 seed 的均值）；**或**
2. 直行 / 高度 / 停止任一段相对 anchor **退化** > 0.05
   （说明有界残差仍在破坏 base）。

## 2. 实验 E-T · FP32 教师的行为保持

### 目标函数

```
L = L_PPO  +  beta * E_s~D [ KL( pi_teacher(.|s) || pi_student(.|s) ) ]
```

| 项 | 取值 |
|---|---|
| `teacher` | `SOLID_FP32_V2`，**冻结，FP32 执行** |
| `student` | 全策略 W8A8 QAT（与 `qat_w8a8_v2_long` 完全相同的设置） |
| `beta` | `{0, 1.0}` 两个臂。`beta=0` **就是**已有的 `qat_w8a8_v2_long`，不重跑 |
| `D` | **student 自己的 on-policy rollout**（goal4.md §8） |
| 其余 | task / seed / envs / iters / init 全部不变 |

### 为什么需要它

Goal 4 的目标审计结论：**当前 QAT 的目标函数里不存在任何行为保持机制。**
损失是 PPO 代理 + 价值 − 熵，`--init-from` 只加载权重、不加载优化器状态，
与参考策略的唯一联系是**初始化**，而初始化不是约束。
PPO 的自适应 KL 是对**上一步策略**的信任域，不是对**参考策略**的锚。

E-T 直接补上这一项，并把它作为 E-R 的对照：

* **E-R** 通过**架构**保持行为（冻结 + 有界）。
* **E-T** 通过**目标函数**保持行为（KL 惩罚）。

两者都失败 → 行为保持不是缺失的要素，责任回到 W8A8 的表达能力本身。

### 状态分布的陷阱

教师 KL 必须在 **student 访问到的状态**上计算，不是教师的。
在教师状态上做蒸馏会得到一个在自己的状态分布下没被约束过的 student——
这是模仿学习里的经典复合误差问题。这一点写进设计，
因为它是这个实验最容易被做错的地方。

### 预测

* **支持**：`beta=1.0` 的转向优于 `beta=0`，且 arm A（浮点执行）
  不再全零——KL 锚把 student 拉在教师附近。
* **证伪**：转向不变。那么"QAT 破坏了参考策略"虽然是**事实**（已测量），
  却**不是**转向失败的**原因**。

## 3. 执行顺序与预算

goal4.md 要求"信息增益优先于计算量"，且失败定位前不做大扫描。

| 顺序 | 实验 | 前置 | 预算 |
|---|---|---|---|
| 0 | `qat_v2_fixlr` / `qat_v2_w8a16` | 进行中 | 2 × 2.6 h |
| 1 | **E-R**，seed 1 | 需要 §0 的固定学习率 | 2.6 h |
| 2 | **E-T** `beta=1.0`，seed 1 | 同上 | 2.6 h |
| 3 | 胜者补 seed 2、3 | 仅当 1 或 2 通过判定 | 2 × 2.6 h |

**在第 0 步完成之前不启动第 1 步。** 若 `qat_v2_fixlr` 恢复了转向，
E-R 与 E-T 的动机都会改变——问题就变成了纯粹的优化器问题，
而不是行为保持问题，那时这两个实验的优先级应当下降。

## 4. 共享的比较规则

* 单一变量。除表中列出的差异外，task / seed / envs / iters / init / act_fracs
  / `desired_kl` 全部固定。
* 每个 checkpoint 记录 sha256；**权重逐位相同就是 bug，直到被证明不是**
  （本项目已经被这个坑过一次：三个不同奖励权重产出了 bit-identical 的策略）。
* 每个 arm 都跑 **A 浮点 / B fake-quant / C 定点** 三条执行路径，
  而不只是 B——arm A 是"参考策略是否被保住"的直接读数。
* 负结果与正结果同等记录，并回写 `goal4_hypotheses.md`。
